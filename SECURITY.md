# Security Policy

AegisAI is currently a research compiler prototype and must not be treated as a production security enforcement boundary.

## Reporting vulnerabilities

Please report compiler bugs that could bypass documented static checks through a private GitHub security advisory when the repository supports it. Avoid publishing exploit details before maintainers have had an opportunity to investigate.

Particularly relevant issues include unintended information-flow bypasses, taint bypasses, capability escalation, authorization bypasses, trust-check bypasses, undeclared effects, or rollback validation errors.

## Supported versions

| Version | Security fixes |
| --- | --- |
| 0.2.x | Yes |
| 0.1.x | No |
