# AegisAI v0.4.0 — Production Trust Fabric

AegisAI v0.4.0 extends verified autonomous execution into a distributed trust fabric for AI-native cyber-defense systems spanning Cloud, Edge and 5G/6G environments. The release adds Ed25519 capability credentials, typed effect adapters, Digital Twin connectors, explicit deployment placement constraints and externally verifiable provenance anchors.

AIR 0.4 carries trust, deployment and execution metadata end-to-end. External effects and remote Digital Twin access remain explicit and opt-in, preserving AegisAI's central invariant: intelligence may propose, but authority must be bounded, verifiable and attributable.

## Highlights

- Ed25519 capability credentials and key IDs
- typed simulation/external effect adapters
- context and opt-in HTTPS Digital Twin connectors
- Cloud/Edge/5G/on-prem placement constraints
- runtime placement verification
- Ed25519-signed provenance roots
- `aegis keygen`
- anchored audit verification
- AIR 0.4
- compatibility with v0.3 HMAC tokens
